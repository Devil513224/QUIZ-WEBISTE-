# Learn With TG (frontend preview)

Static site. No build step. The whole site is index.html.

## Deploy on Vercel

Option A: GitHub
1. Create a GitHub repository and upload these files (index.html, vercel.json).
2. In Vercel: Add New > Project > import the repository.
3. Framework Preset: Other. Leave Build Command and Output Directory empty.
4. Deploy.

Option B: Vercel CLI
1. npm i -g vercel
2. cd into this folder
3. vercel        (preview deploy)
4. vercel --prod (production deploy)

## Notes
- All content is demo data. Backend (Firebase) is not connected yet.
- Progress and settings are saved in the visitor's browser (localStorage) only.
